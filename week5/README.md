# Week 5 — EBO

Бұл зертханалық жұмыста Element Buffer Object (EBO) қолданылды.

Алдымен 4 вершина және 6 индекс арқылы түрлі-түсті төртбұрыш салынды. glDrawArrays орнына glDrawElements қолданылды.

1-тапсырмада индекстер {0, 1, 2} болып өзгертілді. Нәтижесінде төртбұрыштың орнына бір үшбұрыш шықты.

2-тапсырмада 5 вершина және 9 индекс арқылы түрлі-түсті бесбұрыш жасалды.

3-тапсырмада бір VAO, VBO және EBO арқылы екі төртбұрыш салынды. glUniform2f арқылы олардың орындары өзгертілді.

Delta time көмегімен қозғалыс FPS-ке тәуелсіз жасалды. W және S пернелері қозғалыс жылдамдығын басқарады.

Соңғы нұсқада екі төртбұрыш шеңбер бойымен қозғалып, үлкейіп-кішірейеді.
