# Компьютерлік графика (C++ / OpenGL 3.3)

Бұл репозиторийде компьютерлік графика пәні бойынша апталық жұмыстарым жиналған. Барлық жұмыс C++17, GLFW, GLAD және GLM кітапханаларымен жазылған. Әр аптаның өз бумасы бар, оның ішінде `main.cpp` және түсіндірмесі бар `README.md` жатыр.

## Апталар

| Апта | Тақырып | Бума |
|---|---|---|
| 1 | GLFW терезесі, фон анимациясы, FPS | [week1](week1/) |
| 2 | Үшбұрыш, VBO және VAO | [week2](week2/) |
| 3 | Шейдерлер және төбе түстері | [week3](week3/) |
| 4 | Uniform және delta time | [week4](week4/) |
| 5 | EBO және `glDrawElements` | [week5](week5/) |
| 6 | Анимация, гравитация және синхронды қозғалыс | [week6](week6/) |
| 9 | Камера, `lookAt`, WASD | [week9](week9/) |
| 10 | Тінтуірмен еркін камера, yaw/pitch, fov зум | [week10](week10/) |

Бұдан бөлек, [space_shooter_basic](space_shooter_basic/) бумасында СӨЖ ретінде жасаған Space Defender 2D ойыны жатыр.

## Құрастыру

Репозиторийдің түбірінен:

```bash
cmake -S . -B build
cmake --build build --target week10
./build/bin/week10
```

`week10` орнына кез келген аптаның атын жазуға болады: `week1`, `week2`, …, `week9`. Алғашқы құрастыру кезінде CMake GLFW мен GLM кітапханаларын GitHub-тан өзі жүктейді, сондықтан интернет қажет.
