# Week 1 — OpenGL және GLFW

Бұл зертханалық жұмыста OpenGL және GLFW арқылы графикалық терезе жасалды.

1. Терезе өлшемі 1280×720 болып орнатылды.
2. Фон түсі sin() функциясы арқылы уақыт бойынша өзгертілді.
3. Фон түсінің өзгеру жылдамдығы арттырылды.
4. SPACE пернесін басып тұрғанда фон ақ түске өзгереді.
5. SPACE жіберілгенде фон анимациясы жалғасады.
6. glfwSwapInterval(0) арқылы VSync өшірілді.
7. FPS әр секунд сайын терминалға шығарылды.

Нәтиже: бағдарлама дұрыс жұмыс істеді. FPS шамамен 520–745 аралығында болды.

GPU: llvmpipe (LLVM 20.1.2).
OpenGL: 4.5 Core Profile.
