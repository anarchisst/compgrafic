# Week 2

Бір массивте 6 вершина арқылы екі бөлек үшбұрыш салынды.

GL_LINE_LOOP қолданғанда 6 вершина бір контур ретінде байланысып, екі үшбұрыш бір фигура сияқты көрінді.

Wireframe режимінде GL_TRIANGLES сақталды, бірақ glPolygonMode(GL_FRONT_AND_BACK, GL_LINE) арқылы үшбұрыштардың тек контуры көрсетілді.

Fragment shader арқылы үшбұрыштардың түсі қызғылт сарыға өзгертілді.
