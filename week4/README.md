# Week 4

Delta time то есть angle += speed * dt; алып тастағанда онын орнына angle += 0.02f; деп жазганда менің компьютерімде үшбұрыш өте жылдам қозғалды. FPS төмен басқа ноутбукте үшбұрыш баяуырақ қозғалды. Себебі dt қолданылмаса, қозғалыс жылдамдығы FPS-ке тәуелді болады.

Соңғы нұсқада delta time қайта қосылды: angle += speed * dt. Сондықтан қозғалыс FPS-ке тәуелсіз болады.
