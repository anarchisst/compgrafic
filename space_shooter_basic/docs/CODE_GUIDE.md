# Кодтың түсіндірмесі

Орындаған: Байсариев Азамат

Барлық ойын коды main.cpp файлында. Төмендегі жол нөмірлері қазіргі 504 жолдық нұсқаға сәйкес келеді.

## 1 Кітапханалар мен айнымалылар

1-13 жолдарда қажетті кітапханалар қосылады. GLFW терезе мен пернелерге, GLAD OpenGL функцияларын жүктеуге, GLM векторлар мен матрицаларға керек. vector оқтар мен жауларды сақтайды. random жаудың орнын кездейсоқ таңдайды.

15-44 жолдарда ойын айнымалылары орналасқан. Width және Height ойын алаңының логикалық өлшемін береді. Object ішінде position және alive бар. position объектінің орнын көрсетеді, alive оның ойында бар-жоғын білдіреді.

player кеменің орнын сақтайды. bullets және enemies бірнеше объектіні сақтайды. score ұпайды, lives қалған өмірді, gameOver ойынның аяқталуын көрсетеді.

fireTimer келесі оққа дейінгі уақытты, spawnTimer келесі жауға дейінгі уақытты, shield уақытша қорғанысты сақтайды.

## 2 resetGame функциясы

46-жолдан басталады. Кемені төменгі ортаға орналастырады, оқтар мен жауларды тазалайды, ұпайды нөлге, өмірді үшке қояды. Ойын басында бір секунд қорғаныс беріледі.

Бұл функция ойын ашылғанда және Game Over кезінде R басылғанда шақырылады.

## 3 hit функциясы

60-жолдан басталады. AABB тәсілімен екі объектінің соқтығысуын тексереді.

```cpp
glm::vec2 distance = glm::abs(a - b);

return distance.x < halfA.x + halfB.x &&
       distance.y < halfA.y + halfB.y;
```

a және b объектілердің орталықтары. halfA және halfB олардың жарты өлшемдері. Екі осьте де арақашықтық жарты өлшемдердің қосындысынан аз болса, объектілер соқтығысты деп есептеледі.

Кеме мен жау үшбұрыш болып салынғанымен, соқтығысуды жеңілдету үшін төртбұрыштық аймақ қолданылады. Сондықтан үшбұрыштың шетінде шамалы айырмашылық болуы мүмкін.

## 4 updateGame функциясы

67-жолдан басталады. Ойын ережелерінің негізгі бөлігі осы жерде орындалады.

### Қозғалу

```cpp
player += direction * 320.f * dt;
```

direction пернелерден алынған бағыт, 320 бір секундтағы жылдамдық, dt алдыңғы кадрдан бері өткен уақыт. Мысалы, dt 0,01 болса кеме бір кадрда 3,2 бірлік қозғалады.

Диагональ бағыттың ұзындығы бірден артық болса, normalize арқылы бірге келтіріледі. Бұл қиғаш қозғалыстың жылдамырақ болуына жол бермейді. clamp кемені экран шекарасында ұстайды. Өте ұзақ кадрда dt ең көбі 0,05 секунд болады.

### Оқ ату

```cpp
if (fire && fireTimer <= 0) {
    bullets.push_back({player + glm::vec2(0, -30)});
    fireTimer = 0.22f;
}
```

Space басылып, таймер аяқталса, кеменің алдынан оқ жасалады. Бірден кейін таймер 0,22 секундқа қойылады. Сондықтан оқ әр кадрда жасалмайды, бірақ жасалған оқ әр жаңарту кезінде қозғалады.

```cpp
bullet.position.y -= 600 * dt;
```

Y жоғары бағытта азаяды. Оқтың жылдамдығы секундына 600 бірлік.

### Жаудың шығуы

spawnTimer нөлге жеткенде uniform_real_distribution 30 мен 970 арасынан X таңдайды. Жау Y = 85 нүктесінде пайда болады. Келесі жау 0,8 секундтан кейін шығады.

```cpp
enemy.position.y += 110 * dt;
```

Жау төмен қарай секундына 110 бірлік жылжиды. Қозғалысы тұрақты, ойыншыны іздемейді және оқ атпайды. Төменгі шекарадан шыққан жау өшіріледі, ойыншы өмірі азаймайды.

### Оқтың жауға тиюі

Екі цикл әр тірі оқты әр тірі жаумен салыстырады. hit true болса, екеуінің alive мәні false болады және 100 ұпай қосылады. break бір оқтың бірнеше жауды қатар жоюын тоқтатады.

### Жаудың кемеге тиюі

hit арқылы жау мен кеме тексеріледі. Тиген жау өшіріледі. shield нөл болса бір өмір азаяды және 1,5 секунд қорғаныс қосылады. Қорғаныс біткенше келесі соқтығысудан өмір азаймайды. lives нөлге жетсе gameOver true болады.

### Өшкен объектілерді тазалау

remove_if тірі емес объектілерді тізімнің соңына жылжытады. erase сол бөлікті өшіреді. Объектілер цикл ішінде бірден өшірілмейді, бұл тізімді қауіпсіз қарап шығуға көмектеседі.

## 5 compileShader және createGraphics функциялары

compileShader 166-жолдан, createGraphics 186-жолдан басталады. Алғашқысы шейдерді компиляциялап, қате болса хабарлама шығарады. Екіншісі екі шейдерді бір бағдарламаға біріктіреді және геометрияны GPU-ға жүктейді.

Vertex shader ішіндегі негізгі өрнек:

```glsl
gl_Position = uProjection *
    vec4(aPosition * uSize + uOffset, 0.0, 1.0);
```

aPosition бастапқы төбе координатасы. uSize объектіні масштабтайды. uOffset орнын ауыстырады. uProjection логикалық координаталарды экранға арналған координаталарға түрлендіреді.

Fragment shader uColor арқылы берілген түсті қолданады. Шейдерлер бөлек файлда емес, C++ ішіндегі екі мәтін жолында жазылған. Екеуінде де #version 330 core көрсетілген.

VBO ішінде төртбұрышқа арналған төрт төбе және үшбұрышқа арналған үш төбе бар. Бір төбеде екі float координатасы сақталады. VAO осы мәліметтің қалай оқылатынын сақтайды. EBO төртбұрышты екі үшбұрыш арқылы салуға арналған алты индексті сақтайды.

glm::ortho сол жақ жоғарғы бұрышты (0, 0), оң жақ төменгі бұрышты (1000, 700) етіп қояды. Сондықтан төмен жүргенде Y өседі.

## 6 draw функциясы

294-жолдан басталады. Орны, өлшемі және түсі uniform арқылы жіберіледі.

```cpp
glDrawArrays(GL_TRIANGLES, 4, 3);
glDrawElements(GL_TRIANGLES, 6, GL_UNSIGNED_INT, nullptr);
```

Бірінші команда VBO-дағы бесінші төбеден бастап үш төбені салады. Екіншісі EBO-дағы алты индекс бойынша екі үшбұрыштан төртбұрыш жасайды. Бір функция барлық объектілерге қайта қолданылады.

## 7 Font және text

Font 307-жолдан, text 332-жолдан басталады. Әр әріп бес баған мен жеті қатардан тұрады. Кестедегі сандар әр қатарда қай ұяшықтарды бояу керек екенін көрсетеді.

text биттерді тексеріп, белсенді ұяшықтарға шағын төртбұрыш салады. Score, Lives және Game Over осылай шығады. Сыртқы қаріп файлы қолданылмайды.

## 8 renderGame функциясы

357-жолдан басталады. Экранды қара түске тазалайды, терезе өлшеміне сәйкес viewport есептейді және объектілерді салады. Пропорция сақталады, артық жерде қара жолақ қалады.

Кеме ақ түсті, қорғаныс кезінде көгілдір болады. Жаулар қызыл, оқтар көгілдір. Жаудың биіктігі теріс берілгендіктен оның үшбұрышы төмен қарайды.

Game Over болса тек ұпай, өмір және аяқталу жазуы көрсетіледі. updateGame бұл күйде бірден тоқтайды.

## 9 main функциясы

401-жолдан басталады. GLFW іске қосылады, OpenGL 3.3 Core контексті сұралады және терезе жасалады. gladLoadGL функциялардың мекенжайларын жүктейді.

Негізгі циклдің реті:

1. glfwPollEvents арқылы оқиғаларды өңдеу.
2. Пернелерден қозғалыс бағытын алу.
3. glfwGetTime арқылы өткен уақытты есептеу.
4. Терезе фокуста болса updateGame шақыру.
5. renderGame арқылы кадрды салу.
6. glfwSwapBuffers арқылы дайын кадрды көрсету.

Ойын терезесі фокуста болмаса симуляция жаңармайды. Шыққанда буферлер, VAO, шейдер бағдарламасы және терезе босатылады.

## Қорғауда қысқа айтуға болатын түсіндірме

Мен объектілерді OpenGL арқылы салдым. Олардың төбелері VBO-да сақталады, VAO төбелердің құрылымын сипаттайды. Vertex shader өлшем мен орынды өзгертеді, fragment shader түс береді. Қозғалыс delta time арқылы есептеледі. Жаулар белгілі уақыт сайын кездейсоқ X координатасында пайда болады. Оқ пен жау AABB арқылы тексеріледі. Соқтығысса оқ пен жау өшіріліп, ұпай қосылады.
