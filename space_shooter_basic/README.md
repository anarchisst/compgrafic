# Space Defender 2D

Компьютерлік графика пәні бойынша СРС

Орындаған: Байсариев Азамат

Бұл жобада C++ және OpenGL арқылы қарапайым 2D ғарыш ойынын жасадым. Ойыншы кемені басқарады, жоғарыдан түсетін жауларға оқ атады және ұпай жинайды. Графикалық объектілер төбелер мен шейдерлер арқылы салынады.

![Ойын көрінісі](docs/preview.png)

[Ойын видеосын ашу немесе жүктеу](video/spaceshooter.mp4)

## Ойын мүмкіндіктері

- Төрт бағытта қозғалу.
- Space пернесін ұстап тұрып оқ ату.
- Кездейсоқ көлденең орыннан шығатын жаулар.
- Әр жойылған жау үшін 100 ұпай.
- Үш өмір және соқтығысудан кейін 1,5 секунд қорғаныс.
- Game Over және қайта бастау.

Бұл қарапайым нұсқада музыка, дыбыс, бонустар және қозғалатын фон жоқ.

## Басқару

| Перне | Әрекет |

## Ubuntu WSL арқылы іске қосу

Бұл папка compgrafic репозиторийінің ішінде тұруы керек. GLAD көршілес external/glad папкасынан алынады.

Алғашқы жинауға қажетті пакеттер:

```bash
sudo apt update
sudo apt install build-essential cmake libgl1-mesa-dev xorg-dev
```

Жинау және іске қосу:

```bash
cd ~/compgrafic
cmake -S space_shooter_basic -B space_shooter_basic/build-linux -DCMAKE_BUILD_TYPE=Release
cmake --build space_shooter_basic/build-linux -j 4
./space_shooter_basic/build-linux/space_defender_basic
```

Алғашқы конфигурацияда интернет керек. CMake GLFW 3.4 және GLM 1.0.1 кітапханаларын жүктейді. WSL-де ойын терезесін көрсету үшін WSLg сияқты графикалық орта қажет.

## Қолданылған технологиялар

C++17, OpenGL 3.3 Core, GLFW, GLAD, GLM және CMake қолданылды. Дайын ойын қозғалтқышы қолданылмайды.

VAO төбе атрибуттарының баптауын сақтайды. VBO төбелерді GPU жадына жүктейді. EBO төртбұрыштың индекстерін сақтайды. Vertex shader объектінің өлшемі мен орнын есептейді. Fragment shader түсін береді. Uniform арқылы проекция, орын, өлшем және түс жіберіледі.

## Ойынның орындалуы

Әр кадрда пернелер оқылады, өткен уақыт есептеледі, объектілер қозғалады, соқтығысулар тексеріледі және жаңа кадр салынады. Қозғалыс жылдамдығы delta time арқылы есептеледі.

Оқ пен жау соқтығысса, екеуі де өшіріледі. Жау кемеге тисе бір өмір азаяды. Үш өмір біткенде Game Over көрсетіледі.
